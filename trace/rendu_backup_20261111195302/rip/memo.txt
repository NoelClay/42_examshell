# 입력, 출력, 제약조건

입력: 하나의 문자열 인자로 괄호세트가 나옴


출력: 올바른 괄호셋트를 출력한다. 
올바른 괄호 세트가 없다면 최소한의 괄호를 제거하여 만들어진 문자열 세트들을 줄바꿈으로 구분하여 출력한다.


제약조건:
Allowed functions: puts, write


# 유추

괄호를 잡아먹는 방식의 알고리즘은 스택을 활용하는게 일반적이다.

재귀를 하는것 자체가 스택인데, 제거해야될 괄호의 갯수는 단한번 반복하는 것만으로도 결정될 수 있다.

( : open_cnt++
) : open_cnt-- || close_cnt++

이런식이면 둘다 0, 0 일수도있다. 그러면 지울게 단하나도 없이 그냥 출력하면 정답이다.

open 이나 close 나 0보다 큰 갯수가 존재하면 그 괄호들을 뭐가 되었든 제거해야지 된다는 소리이다.

재귀를 타면서 0,0 을 만들었다 하더라도 끝까지 문자열을 가야지 의미가 있다. 

그리고 또한 의미없는 괄호를 제거하는 경우가 있을 수 있다. -> 그래서 하나가 더 필요함. 
open이 제거되지 않았다면 0보다 크게 남아있어야되는 remain 변수가 필요하다. 

재귀는 끝까지 가면서 결국 추가되냐 안추가되냐만 필요하다.
