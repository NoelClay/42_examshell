# 입, 출, 제

입력
정수 한개. 이것의 의미는 정수 X 정수 체스칸에 정수개의 퀸이 들어간다는 의미다.

출력
이제 그러한 퀸이 들어갈 수 있는 모든 경우의 수를 공백으로 구분된 정수 문자열로 표현하고 각 정수 문자열은 줄바꿈으로 구분된다.

한 문자열의 의미는 0열, 1열, 2열,... 각 열마다 퀸의 행위치이다.


제약조건
Allowed functions : atoi, fprintf, write, calloc, malloc, free, realloc, stdout, stderr




# 유추

전형적인 백트래킹이다. 특히 이미 출력 포맷이 주어진이상 더 간단하게 코딩이 가능해진다. 

2차원 배열없이도 퀸이 올수 있냐 없냐를 판단할 수 있다. 

일단 열마다 재귀를 탄다. 따라서 재귀 최대 깊이 자체는 N이다. 

그리고 그 열에대한 재귀가 호출될때 비교할 것은 다음과 같다.
이전의 열들 정보를 단순하게 탐구하며 같은 행에 존재하는게 하나라도 있는지, 
같은 왼쪽 윗대각선 혹은 아랫쪽 대각선에 존재하는게 하나라도 있는지를 판별하는것만으로 충분하다.

DP가 필요 없다.

충분하면 추가하고 다음 재귀를 불러오면 된다. 될때까지 행을 탐색하다가 도저히 없어? 그러면 백트래킹이다.

그렇게 가다가 최대 길이에 도달하면 오나성된것이니 출력을 해주고 백트래킹하면 된다.
