# 입력, 출력, 제약조건 정리

입력: 서식지정자가 포함된 문자열 인자, 가변인자

출력: scanf의 구현

제약조건: 

Allowed functions: fgetc, ungetc, ferror, feof, isspace, isdigit, stdin, va_start, va_arg, va_copy, va_end

 It will manage only the following conversions: s, d, and c

---

man

 The scanf() function reads input from the standard input stream
       stdin

On success, these functions return the number of input items
       successfully matched and assigned; this can be fewer than provided
       for, or even zero, in the event of an early matching failure.

The value EOF is returned if the end of input is reached before
       either the first successful conversion or a matching failure
       occurs.  EOF is also returned if a read error occurs, in which
       case the error indicator for the stream (see ferror(3)) is set,
       and errno is set to indicate the error.

# 역할 분할, 모듈화

이미 함수가 주어진 만큼 해당 함수들의 목적을 분석한다.

1. int ft_scanf(const char *format, ...)
ap 초기화, 로직 시작하고, ap end

2. int ft_vfscanf(FILE *f, const char *format, va_list ap)
file이 비어있지 않으면 메인 로직 시작
%면 그 다음 인자를 바라보고 매칭이 안되면 바로 break -> matcing은 match_conv 이다.
ncov++는 기본

%가 등장하기 전까지는 일단 최초 앞단공백은 그냥 스킵이다. 
그 다음부터 유효한 문자열부터는 match_char로 정확하게 일치해야된다.

3. int match_conv(FILE *f, const char **format, va_list ap)

c, d, s 분기

4. int scan_string(FILE *f, va_list ap)

s에서는 이미  space 스킵이 일어난 상태이고, 이후 진짜 s에 '단어'를 저장한다. 그 말은 즉 space가 나오기 전까지 누적해서 저장하고 만들어야된다.

5. int scan_int(FILE *f, va_list ap)

d는 일단 첫부호만 인식하고, 나머지는 숫자가 아닐때까지만 인식해서 전부 누적해서 숫자를 세서 저장한다.


6. int scan_char(FILE *f, va_list ap)

그냥 공백이든 뭐든간에 문자 하나 역참조 저장한다.

7. int match_char(FILE *f, char c)

문자 하나하나 정확히 일치하는지를 체크

8. int match_space(FILE *f)

유효 문자가 나오기 전까지 공백 싸그리 잡아먹기
