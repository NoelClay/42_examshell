# 재정의 3요소 입력, 출력, 제약조건

## 입력
표준입력에서 그냥 전체를 싸그리 받을거야. : 문자열
그리고 argv에서 딱 한개 받음 : 문자열

## 출력
filter에 의해 *로 치환된 표준입력이 표준 출력으로 : 문자열

## 제약조건
Allowed functions: read, write, strlen, memmem, memmove, malloc, calloc,
realloc, free, printf, fprintf, stdout, stderr, perror

실제 시스템 에러라면 perror("Error :") 를 활용하여 에러가 발생할때는 반드시 
표준에러에 Error: 로 시작하는 문자열을 출력하고 1로 종료해야됨.

arg가 없거나, 비었거나, 1개이상이거나, 그러면 전부 그냥 1리턴으로 종료

# 모듈화 해보기

1. 초기 에러 탈출: 그냥 1리턴으로 끝나는 간단한 조건문

2. res free 처리를 해줘야되는 상황에서 복잡해지니, free error return 이라는 헬퍼 함수 : helper_error

3. 표준 입력이 EOF가 뜰때까지 일단 문자열을 온전히 받아내기 : read_full

4. 인자로 받은 문자열 주소로부터 filter의 길이만큼 matching이 온전히 되는지 검사: match_filter

5. filter 처리기. 특히 4번을 활용하여 전체를 치환시켜주는 녀석: filter_exec

6. 실행기 : main
