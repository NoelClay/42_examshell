# 재정의: 입력, 출력, 제약조건

입력은 표준 입력에서 입력이 될것이다.

출력은 반드시 \n을 포함해서 \n으로 끝나는 한줄을 반환해야함. EOF에 도달한 경우에는 남은 내용을 전부 반환함.

당연히 문자열의 끝은 항상 널종단문자이다.

에러가 발생하면 NULL을 반환해야한다. 버퍼가 비어있어도 NULL반환

제약조건은 read, free, malloc만
