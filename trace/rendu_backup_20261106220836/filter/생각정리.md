# 내 말로 간단히 재정의
./filter "문자열"
이렇게 인자를 받는 순간 stdin으로부터 파일 입력을 받는다. random buffer size? 솔직히 이게 뭔소리인지 모르겠다. 그냥 내가 구현하는 함수인데 뭔 랜덤 버퍼이고 자시고가 어딨어 내가 그냥 불러오고 저장하는 버퍼가 그게 버퍼지. 그런데 중요한건 읽어온 문자열이 내가 지정한 사이즈만큼이라면 이건 끝인지 중간인지 그게 문제이다.

자 중간에 짤린거라면 이것을 이어서 검사를 해야된다. 즉 우리는 일단 하나의 거대한 문자열을 계속해서 reallocation 해가며 일단 완성을 해야됨.

그렇게 완성된 문자열을 가지고 이제 인자로 받은 검사 문자열이 있는지를 찾고 참이라면 *로 바꾸는 로직이 필요하겠지.

입력: argc 는 반드시 2강제, argv가 검사 문자열, stdin에는 키보드 입력이 되었건, 파일이 되었건, 파이프가 되었건 뭔가가 연결되어 있고 그건 텍스트스트링의 형태일것이어야할것이다. 

출력: stdin을 받아서 처리된 문자열을 표준 출력으로 출력

제약조건: 뭐 성능 제약이 있는 문제는 아닌거 같고, 스택공간 안쓸거니 상관 없고, 허용된 함수들 man page 보면서 라이브러리 잘 포함시켜서 구현하면 될듯
