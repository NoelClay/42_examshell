# 모듈화 해결전략 유추

- `distance`: 피타고라스 정리(`sqrtf(dx*dx + dy*dy)`)로 두 도시 좌표 간의 직선 거리 반환.
- `total_distance`: `path` 배열의 인덱스 순서대로 `path[0] -> path[1] -> ... -> path[n-1]`까지 잇고, 마지막에 `cities[path[n-1]]`에서 `cities[0]`으로 돌아오는 거리를 더해 닫힌 한 바퀴 경로의 총 길이를 구함.
- `solve`: 
  - 기저조건: `pos == n`일 때 모든 도시 배치가 끝났으므로 `total_distance`를 계산하여 `*min` 최솟값 갱신 후 리턴.
  - 재귀 탐색: 현재 자리(`pos`)에 앉힐 후보를 아직 안 쓴 후보들(`pos ~ n-1`) 중에서 골라와서(`swap`), 다음 자리(`pos + 1`)로 넘겨주고, 탐색이 끝나 돌아오면 다시 원래대로 되돌려놓음(`swap`).
- `main`: 0번 도시는 출발점으로 고정해두고 `pos = 1`부터 `solve`를 호출하여 원순열 회전 대칭성으로 인한 11배 중복 연산을 제거.

# 가장 쉬운 해결방법 정리

1. **입력 및 예외 처리**: `fscanf(stdin, "%f, %f", ...)`로 도시를 읽고, `n < 2`이면 즉시 `0.00` 출력 후 종료.
2. **초기화**: `path` 배열에 `0, 1, 2, ..., n-1` 인덱스를 순서대로 채워넣음.
3. **탐색 시작**: 0번은 출발점으로 고정하고 `solve(cities, path, n, 1, &min)` 호출.
4. **재귀 탐색 (`solve`)**:
   - `pos == n`이면 거리 계산 및 최솟값 비교 갱신 후 즉시 `return`.
   - `i = pos`부터 `n - 1`까지 반복:
     - `swap(path, pos, i)` (후보 배치)
     - `solve(cities, path, n, pos + 1, min)` (다음 자리 결정)
     - `swap(path, pos, i)` (원상복구)
5. **결과 출력**: `printf("%.2f\n", min)`으로 최단 거리 소수점 둘째 자리까지 출력.

# 주의할 점

1. **루프 시작 인덱스 (`i = pos`)**:
   - `0 ~ pos-1`은 이미 앞선 단계에서 순서가 확정된 자리이므로 절대 건드리면 안 됨.
   - `i = 0`부터 돌리면 이미 확정한 0번 출발점과 앞자리 도시들이 엉망으로 섞여서 오답 발생.
2. **원점 복귀 거리 누락 금지**:
   - `total_distance`에서 도시 간 연결(`path[i]` -> `path[i+1]`)만 하고 마지막 도시에서 출발 도시(`cities[0]`)로 돌아오는 거리를 더하지 않으면 한 바퀴 도는 경로가 아니게 됨.
3. **컴파일 플래그**:
   - `sqrtf` 함수를 사용하므로 컴파일 시 반드시 맨 뒤에 `-lm` 플래그를 붙여야 함.
4. **기저 조건 미반환 주의**:
   - `pos == n`에서 거리 계산 후 반드시 `return`을 해줘야 뒤의 루프나 배열 범위 밖 접근을 막을 수 있음.
